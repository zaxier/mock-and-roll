## Dataset Generation Pattern

Edit `src/my_retail_demo/datasets.py`. The key function is `generate_datamodel()`:

```python
from typing import List
import random
import pandas as pd
from mimesis import Person, Finance, Datetime, Numeric, Address, Choice
from mimesis.locales import Locale

from .core import DataModel, Dataset, Config


def generate_users(num_records: int = 100) -> pd.DataFrame:
    person = Person(Locale.EN)
    dt = Datetime()
    address = Address()
    choice = Choice()

    return pd.DataFrame({
        'user_id': [person.identifier() for _ in range(num_records)],
        'full_name': [person.full_name() for _ in range(num_records)],
        'email': [person.email() for _ in range(num_records)],
        'city': [address.city() for _ in range(num_records)],
        'signup_date': [dt.date(start=2020, end=2025) for _ in range(num_records)],
        'segment': [choice.choice(['individual', 'business']) for _ in range(num_records)]
    })


def generate_transactions(user_ids: List[str], num_records: int = 500) -> pd.DataFrame:
    finance = Finance()
    dt = Datetime()
    person = Person()
    numeric = Numeric()
    choice = Choice()

    return pd.DataFrame({
        'transaction_id': [person.identifier(mask='TXN-########') for _ in range(num_records)],
        'user_id': [random.choice(user_ids) for _ in range(num_records)],
        'amount': [finance.price(minimum=10, maximum=1000) for _ in range(num_records)],
        'date': [dt.date(start=2024, end=2026) for _ in range(num_records)],
        'quantity': [numeric.integer_number(start=1, end=10) for _ in range(num_records)],
        'method': [choice.choice(['Credit Card', 'Debit Card', 'PayPal']) for _ in range(num_records)]
    })


def generate_datamodel(config: Config, num_records: int = None) -> DataModel:
    base_records = num_records or config.records

    users_df = generate_users(base_records // 5)
    users = Dataset(name="users", data=users_df)

    txn_df = generate_transactions(users_df['user_id'].tolist(), base_records)
    transactions = Dataset(name="transactions", data=txn_df)

    return DataModel(datasets=[users, transactions])
```

## Critical Warnings

### Mimesis Date Handling
- `dt.date(start=2020, end=2025)` expects INTEGER years, not datetime objects
- If using datetime objects, extract the year: `datetime.now().year`

### Mimesis Numeric Handling
- Use `start=` and `end=` params: `numeric.float_number(start=10.0, end=1000.0)`
- DO NOT use `min=` or `max=`

### Choice Provider
- `choice.choice(['a', 'b', 'c'])` for single random selection
- Does NOT support weights like Python's random library

## Mimesis Provider API Reference

### Address Provider
- `address()` - Full street address
- `city()` - City name
- `state(abbr=False)` - State/province
- `postal_code()` - ZIP/postal code
- `country()` - Country name
- `coordinates(dms=False)` - Latitude/longitude
- `street_number(maximum=1400)` - Street number

### Person Provider
- `full_name(gender=None)` - Complete name
- `first_name(gender=None)` - Given name
- `last_name(gender=None)` - Family name
- `email(domains=None, unique=False)` - Email address
- `phone_number(mask="")` - Phone number
- `birthdate(min_year=1980, max_year=2023)` - Date of birth
- `occupation()` - Job/profession
- `username()` - Username
- `identifier(mask="##-##/##")` - Custom ID pattern

### Finance Provider
- `company()` - Company name
- `price(minimum=500, maximum=1500)` - Monetary amount
- `currency_iso_code()` - Currency code
- `bank()` - Bank name
- `stock_ticker()` - Stock symbol

### Datetime Provider
- `date(start=2000, end=current_year)` - Date object (INTEGER years!)
- `datetime(start=current_year, end=current_year)` - Datetime object
- `time()` - Time object
- `timestamp()` - Unix timestamp
- `formatted_date(fmt="")` - Custom date format

### Numeric Provider
- `integer_number(start=-1000, end=1000)` - Random integer (use start/end, NOT min/max!)
- `float_number(start=-1000.0, end=1000.0)` - Random float
- `integers(start=0, end=10, n=10)` - List of integers
- `floats(start=0, end=1, n=10)` - List of floats

### Choice Provider
- `choice(*args)` - Single random choice from sequence

### Internet Provider
- `url()` - Web URL
- `email()` - Email address
- `ip_v4()` / `ip_v6()` - IP addresses
- `mac_address()` - MAC address
- `hostname()` - Domain hostname

### Text Provider
- `text(quantity=5)` - Multiple sentences
- `sentence()` - Single sentence
- `word()` / `words(quantity=5)` - Words
- `title()` - Title text

### Payment Provider
- `credit_card_number(card_type=None)` - Credit card number
- `credit_card_expiration_date()` - Expiry date
- `cvv()` - Security code

### Food Provider
- `dish()` - Food dish name
- `fruit()` / `vegetable()` - Produce names
- `drink()` - Beverage name

### Development Provider
- `programming_language()` - Language name
- `version()` - Semantic version
- `boolean()` - True/False

### Cryptographic Provider
- `uuid()` - UUID string
- `hash(algorithm=None)` - Hash value
- `token_hex(entropy=32)` - Hex token

### Hardware Provider
- `cpu()` / `ram_size()` / `graphics()` - Computer specs
- `manufacturer()` - Hardware maker

### Transport Provider
- `manufacturer()` / `car()` / `airplane()` - Vehicle data

## Tips for Good Datasets

1. Create multiple related datasets with foreign key relationships (star schema)
2. Scale dimension tables smaller than fact tables (e.g., 1:5 ratio)
3. Generate dimension tables first, then use their IDs in fact tables
4. Use realistic field names that match the business domain
5. Test with `python -m my_retail_demo --records 100` before generating large datasets

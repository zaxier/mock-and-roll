# my_retail_demo

Synthetic data pipeline for Databricks, generated by [mock-and-roll](https://github.com/your-org/mock-and-roll).

## Quick Start

### Run locally (development)

```bash
python -m my_retail_demo --catalog dev --schema my_schema --records 1000
```

### Build a standalone wheel

```bash
pip install build
python -m build
```

### Install and run the wheel anywhere

```bash
pip install dist/my_retail_demo-1.0.0-py3-none-any.whl
python -m my_retail_demo --catalog prod --schema client_demo
```

## CLI Options

| Flag | Description | Default |
|------|-------------|---------|
| `--catalog` | Databricks catalog name | `dev` |
| `--schema` | Databricks schema name | `default` |
| `--volume` | Databricks volume name | `sample_data` |
| `--records` | Number of records to generate | `1000` |
| `--log-level` | Logging level | `INFO` |

## Project Structure

```
src/my_retail_demo/
├── __init__.py
├── __main__.py      # Entry point
├── main.py          # Pipeline orchestrator
├── datasets.py      # Dataset generation (edit this!)
└── core/            # Framework utilities (don't edit)
```

## Editing Datasets

Open `src/my_retail_demo/datasets.py` and modify `generate_datamodel()` to create
your custom datasets. Use [mimesis](https://mimesis.name/) for realistic data generation.

To iterate with AI assistance:

```bash
mock-and-roll design
```
